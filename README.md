# HELUM LIMITED — Corporate Website

**Technology. Energy. Possibility.**  
**Engineering the Intelligence of Energy**

Production-ready Next.js website for HELUM LIMITED — a Kenyan technology and renewable-energy company.

## Live / Deploy

Connect this repository to [Vercel](https://vercel.com) for production deployment.

- Framework: Next.js
- Root Directory: `.` (leave blank)
- Build Command: `next build` (default)
- Install Command: `npm install`

## Stack

- Next.js 15 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- SEO (metadata, sitemap, robots, JSON-LD)

## Pages

Home, About, Vision & Mission, Values, Why HELUM, Services (overview + dynamic service pages), Solutions, Who We Serve, Process, Partnerships, Opportunity, Contact (form), Privacy, Terms.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
